# Internet Speed Test

A lightweight browser-based internet speed test built for GitHub Pages.

### Measures
- Latency / ping estimate
- Download speed
- Upload speed
- Browser/network connection information
- Animated live speed gauge

### Run
Open `index.html` locally or publish the repository with GitHub Pages. The test uses Cloudflare's public speed-test endpoints, so results require an internet connection and may vary with network conditions.

### GitHub Pages
In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
